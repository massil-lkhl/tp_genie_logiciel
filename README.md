# Tp_genie_logiciel 

Le projet prends un tableau avec n cases et retourne alors la moyenne, la valeur minimale et maximale.

## Objectif

Ce projet a été réalisé dans le cadre de la licence en informatique.
L’objectif est d'avoir un module Python (StudentStats) capable de gérer des statistiques de notes (moyenne, min, max).

## Fonctionnalités

- Création d'un tableau de n notes 
- Fonction min
- Fonction max
- Fonction Moyenne

## Technologies utilisées

- python
- VsCode 
- Git
